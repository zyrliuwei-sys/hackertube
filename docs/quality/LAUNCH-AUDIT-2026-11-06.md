# HackerTube AI 全站上线检查 — 2026-11-06

检查对象：https://hacker-tube.com；代码基线 `1cda6ea1f594835f93603b9762df3c8914c8f79d`。结论：公开目录、搜索和本地收藏基本可用，视觉和响应式基础良好；需要优先补齐账号恢复、产品入口、学习路线留存、内容质量及运营指标。以下 P1/P2 表示修复优先级，不是漏洞评级。

本轮为检查与报告。没有修改应用代码、生产配置或数据库，没有部署。浏览器收藏和主题测试已恢复原状。

### 1. 账号恢复

生产 `/api/config/public` 返回 `password_reset_enabled: "false"` 和 `email_verification_enabled: "false"`。访问 `/forgot-password` 后显示：`Password reset is not available`，并明确说明未配置邮件服务。代码在 [public config](../../src/routes/api/config/public.ts) 根据邮件配置派生这两个开关，登录页据此隐藏找回入口。

这是实际配置缺口，不是按钮文案问题。现有域名有 Cloudflare MX，但 MX 存在不代表发件服务或 `support@` 收件链路已经验收。本轮没有发邮件。

### 2. 模板付费入口与产品不一致

生产 `/pricing` 展示 Starter $9、Pro $29、Enterprise $99（月付），权益包括 projects、credits、API access、Custom integrations。该页被 sitemap 收录，当前没有 H1。个人中心仍展示 Upgrade、Purchase Credits、Billing、Payments。

来源：[定价目录](../../src/config/pricing.ts) 明确保留了 demo catalog；[用户功能默认值](../../src/config/user-features.ts) 开启 credits、billing、payments。条款却说明当前不宣布付费视频套餐。应先让导航、账户中心、套餐文案、服务条款和真实交付一致。本轮未提交结账，不能据此声称支付可用或支付失败。

免费目录没有订单本身不代表产品失败；当前更有价值的转化应是搜索 → 打开视频 → 收藏/生成路线 → 回访。

### 3. 路线刷新丢失

复现：打开 `/learning-paths` → 输入 `learn Python programming from scratch` → 选择从零开始 → 生成 `Introduction to Python Programming` → 刷新。结果和输入均恢复为默认机器学习示例。

[学习路径 block](../../src/blocks/hackertube-learning-paths.tsx) 第 32 行仅在 React state 中持有生成结果，onSuccess 只调用 setPath。[进度组件](../../src/components/hackertube/learning-path-view.tsx) 保存的是由视频 ID 序列标识的完成进度，没有保存完整路线。可以下载 Markdown，但下载不等于应用中可恢复。

证据：[生成的路线全文](launch-audit-2026-11-06/python-path.txt)、[生成结果截图](launch-audit-2026-11-06/python-path.png)。

### 4. AI 选片难度缺乏可靠约束

上述零基础 Python 请求生成的第三阶段是 `James Powell: So you want to be a Python expert?`，第四阶段是 `How to Speed up a Python Program 114,000 times.`。路线解释仍把它们对应到基本控制结构、简单计算器和列表求和，练习与选片的匹配较弱。

这是一次真实样本，不意味着每次生成都会失败。[validateLearningDraft](../../src/modules/learning-paths/service.ts) 第 337 行起验证结构、候选 ID 和重复 ID，但没有验证初学者的前置知识及课程顺序；机器学习特定目标有人工骨架，Python 等目标没有同等约束。优先增加分阶段候选集、先修检查和常见目标的质量回归案例，而不是单纯增大模型。

### 5. 运营报表与视频产品脱节

[运营服务](../../src/modules/operations/service.ts) 使用 `analytics_visitor.createdAt` 选择访客 cohort，因此时间窗口主要体现首次进入该窗口的访客，不能直接当作该段时间所有回访用户。其 `active` 指标基于登录用户的 `ai_task` 记录。

公开 [学习路线接口](../../src/routes/api/learning-paths.ts) 不写 `ai_task`；搜索、收藏、播放也没有对应的产品事件。[事件目录](../../src/config/events.ts) 主要注册了 `plan_selected`、`paywall_hit`、`risk_flagged`。因此现有“AI/活跃为 0”无法回答是否有人生成学习路线、搜索或观看视频。

建议分别定义：搜索次数和零结果率、视频打开/播放尝试/跳转 YouTube、收藏、路线生成成功/降级/失败/耗时、回访。观看时长需要播放器事件，不能用打开详情页代替。匿名统计应明确隐私和保存周期。

### 6. 依赖安全与安装配置

初次 `pnpm audit` 使用的 npmmirror 没有审计 endpoint；改用 npm 官方 registry 后，生产依赖树报告 **4 moderate、1 low，0 high、0 critical**。这是包级告警数量，不是五条已证实的网站攻击路径。

- `seroval 1.6.8` 命中两条序列化告警。上游分别在 1.6.10、1.6.11 修复；建议升级到包含两项修复的兼容版本。利用分别需要不可信 RegExp 被序列化到脚本，或不可信属性写入 typed array；本轮未发现本站满足这些条件的具体路径。参见上游 [RegExp 公告](https://github.com/lxsmnsyc/seroval/security/advisories/GHSA-9wx9-5pv9-3349) 与 [typed array 公告](https://github.com/lxsmnsyc/seroval/security/advisories/GHSA-f86p-h4j2-7qgj)。注意上游将后一项定为 Low，npm/GitHub 数据库本次报表分级为 Moderate。
- 其他告警来自 esbuild、deepmerge、minimatch，分别位于 drizzle-kit、邮件渲染/CLI、shadcn 工具链等传递依赖。需要按实际运行路径处置，不能将开发服务器告警直接等同于生产 Worker 被攻破。
- 当前 pnpm 11 提示忽略 [package.json](../../package.json) 中的 `pnpm.overrides` / `pnpm.onlyBuiltDependencies`。其中 seroval 仍声明固定 1.6.8；应将有效配置整理到当前 pnpm 支持的位置，并验证最终解析的版本。

完整结果：[依赖审计](launch-audit-2026-11-06/dependencies.json)。

## 检查边界

- 本轮没有确认 P0 或可实际利用的高危漏洞，但并非完整渗透测试。包级告警与真实可利用性分别记录。
- 没有创建测试注册、发送邮件、提交真实付款、退款、修改权限或生产设置，因此这些完整外部链路没有被验收。
- 播放器点击后加载了 YouTube iframe，但当前测试环境显示“请登录，以便我们确认你不是聊天机器人”。这属于本次环境下的上游验证，不能判定所有访客无法播放；也不能把 iframe 成功加载当作视频播放成功。现有 Watch on YouTube 退路保留有效链接。
- 不是逐一播放 6,454 个视频。覆盖的是全部 sitemap 非视频页、28 个视频详情模板样本和全量目录一致性测试。
- 个人中心首轮 axe 在骨架加载阶段报了空链接名称；等待 Free/余额等实际数据加载后复查为 0，未将其当作稳定页面缺陷。
- 明暗与无障碍结果来自 Chromium 自动化和截图检查，不替代真实手机、Safari/Firefox、屏幕阅读器测试。截图里的粉色翻译悬浮按钮来自浏览器扩展。
